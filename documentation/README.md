# documentation/

End-user documentation of Things Mapper — written alongside the
implementation (phase 2 and 3). Planned content:

| Document | Audience | Phase |
|---|---|---|
| `getting-started-android.md` | phone users: install, link a device, first mapping session | 2 |
| `getting-started-desktop.md` | Linux desktop users: install `.deb`, GNSS setup (gpsd), first session | 2 |
| `raspberry-pi-kiosk.md` | builders of an in-vehicle mapping box: image, touch display, autostart, GNSS receiver | 3 |
| `android-auto.md` | drivers: enabling the car screen, what is shown, limitations | 3 |
| `network-servers.md` | how to obtain MQTT credentials on The Things Stack and ChirpStack v4, topic and TLS details | 2 |
| `data-and-privacy.md` | what is stored, what is uploaded to ttnmapper.org, how to export or delete | 2 |
| `troubleshooting.md` | connection, GNSS and upload problems; how to create a bug report | 2 |

Design documents (requirements, functional and technical design) live in
[`design/`](../design/README.md), not here.
